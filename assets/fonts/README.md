# Self-hosted fonts

Final Cog serves these Latin-subset WOFF2 files from this directory; pages do not
request font files from a third-party CDN at runtime.

- Archivo, expanded variable widths, weights 700–800. Source: Google Fonts,
  `ofl/archivo`. License: `Archivo-OFL.txt`.
- IBM Plex Sans, weights 400–500. Source: Google Fonts, `ofl/ibmplexsans`.
  License: `IBM-Plex-Sans-OFL.txt`.
- IBM Plex Mono, weights 400 and 500. Source: Google Fonts, `ofl/ibmplexmono`.
  License: `IBM-Plex-Mono-OFL.txt`.
